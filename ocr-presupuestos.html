01 · Problema

La extracción tiene que ahorrar trabajo sin ocultar incertidumbre.

En presupuestos escaneados, una tabla puede terminar copiada a mano en una hoja de cálculo. Este MVP busca reducir esa fricción sin borrar la revisión humana: la persona puede ver qué se extrajo y dónde conviene mirar de nuevo.

05 · Evidencia técnica

Qué funciona hoy y qué sigue en diseño.

Motor probado

PDF escaneado → datos estructurados

Probé un flujo local de OCR y extracción de tablas de presupuestos con OCRmyPDF, Tesseract, pdfplumber y openpyxl. El resultado se organiza para revisión en Excel.

Validación

Revisión por campo

El proceso distingue método y confianza de extracción por campo y admite correcciones humanas. Estos controles ayudan a detectar valores que requieren comprobación.

Pendiente

Aplicación web y plantillas

La interfaz de esta página es una representación visual con datos ficticios. La selección y reorganización de columnas y la experiencia web siguen como siguientes pasos.

El repositorio del motor es privado; no se presentan los valores ilustrativos de confianza de esta página como métricas medidas sobre datos reales.

01 · Regla

Comprobar el parcial

En este ejemplo, el parcial calculado es metrado × precio unitario. Se contrasta con el valor que aparece en la tabla.

02 · Hallazgo

La fila 01.02 no coincide

18.50 × 120.00 = 2,220.00, pero la muestra contiene 2,210.00. La diferencia de S/ 10.00 queda señalada para revisión humana.

03 · Decisión

No corregir a ciegas

Se revisa el documento de origen antes de confirmar el valor. Una señal de inconsistencia no identifica por sí sola qué campo está equivocado.

Alcance de esta muestra: las cifras y el error se introdujeron deliberadamente para ilustrar criterios de validación. No son tasas de precisión, resultados de un test automatizado ni mediciones del motor.
